05 — Usage Rules
Do & Don't
✓ Do
Use Syne for all headings across all deliverables
Use #3D8B6E as the primary accent everywhere
Use JetBrains Mono for tags, labels, and data readouts
Keep backgrounds light (#F7FAFB) — let the green do the work
Label pipeline stages consistently: Stage 1 / 2 / 3 with ML / Rules / Formula badges
Use "PhysioTwin" as the project name everywhere
✗ Don't
Don't use neon greens (#00E5A0) — they're too electric for print/academic contexts
Don't use UCSD blue as the primary color on the poster — it disconnects from the app/web
Don't use "Pulse" or "Digital Twin" — the project is now "PhysioTwin"
Don't mix Inter and DM Sans in the same deliverable
Don't use dark mode for the poster — print needs light backgrounds
Don't use color as the only differentiator for pipeline stages — use labels too
