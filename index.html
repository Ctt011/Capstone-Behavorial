Digital Twin: Hybrid Stress Detection from Apple Watch

A hybrid stress detection system that combines ML activity classification with validated physiological formulas and a Body Battery energy management interface. Built for Apple Watch via HealthKit. Team: Camille Tran, Dhyay Thakrar, Levy Sahoo, Essie Chang, Selina Zhang Mentor: Tauhidur Rahman Course: DSC 180B Capstone, UC San Diego, Winter 2026

Project Highlights

Innovation and Uniqueness
🧠

Problem

Stress signals are subtle, highly individual, and difficult to learn from small cohorts, so we pivoted to a hybrid system that stays accurate, interpretable, and user-personalized.

📊

Approach

We designed a 3-stage hybrid pipeline for Apple Watch data (HR, HRV, steps, sleep). Stage 1 uses ML to classify physical vs cognitive states (93.6% accuracy), preventing exercise from being mislabeled as stress. Stage 2 applies sleep-based rules to adjust daily sensitivity. Stage 3 computes an HRV-based stress score (0–100) using DC/AC metrics and personal baselines.

✅

Impact

Our core product is the Body Battery, a simple energy percentage that users instantly understand. It drains based on both stress intensity and duration (not just a snapshot), then recommends recovery actions (breathing, walk, meditation, stretch, hydrate). During recovery, the system measures HR/HRV changes via HealthKit to validate improvement and update personal baselines over time, closing the loop from Detect → Quantify → Intervene → Validate → Learn.
